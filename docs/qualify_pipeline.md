# Гид клиента: ИИ-квалификация компаний (Этап 2)

> Короткая инструкция «как пользоваться» для конечного клиента бота.

---

## 1. Тарифы

В Mini App в шапке вы увидите плашку с указанием вашего тарифа.

### Тариф **Simple** — без ИИ

Что включено:
- Парсинг компаний из Rusprofile и Яндекс.Карт.
- Универсальный сорт-балл (0–100), который учитывает «живость» бизнеса.
- Кросс-обогащение источников (опционально).
- Выгрузка в Google Sheets с сортировкой по баллу.

Что **не** включено:
- ИИ-анализ сайтов компаний.
- Автоматическое разделение на «горячие» и «холодные» лиды.

Менеджер сортирует таблицу по сорт-баллу и обзванивает сверху вниз.

### Тариф **AI** — с ИИ-квалификацией

Включает всё из Simple, плюс:
- Создание **ИИ-профилей** под нужный сегмент клиентов (раздел «ИИ-профили» в bottom-nav).
- ИИ читает сайт каждой найденной компании и решает: горячий лид / холодный / неопределено.
- Подсказки для холодных звонков («зацепки»).
- Бюджет на месяц: лимит на компаний и токенов; при достижении 80% — предупреждение.

## 2. Создание ИИ-профиля (только AI)

В Mini App → нижняя навигация → **🤖 ИИ-профили** → **+ Создать профиль**.

**Шаг 1.** Опишите своими словами:
- Что вы продаёте/предлагаете.
- Какие компании ваш идеальный клиент.
- Кто **точно не подходит** (это важно — добавит негативные ключи).

Пример:
> Я продаю корпоративные сувениры и подарки оптовым компаниям. Хочу
> найти оптовиков (канцтовары, бытовая химия, косметика), которые
> могут покупать у меня подарки для своих клиентов. Маленькие розничные
> магазины не подходят, госконторы тоже мимо.

Нажмите **«Подготовить профиль»** — ИИ извлечёт ключевые признаки.

**Шаг 2.** Проверьте результат:
- **Идеальный клиент** — описание для менеджера (read-only).
- **Признаки горячего лида** — критерии, по которым ИИ будет оценивать сайты.
- **Позитивные ключевые слова** — добавляйте/удаляйте chips. Это слова,
  наличие которых на сайте намекает «наш клиент».
- **Негативные ключевые слова** — то, что говорит «НЕ наш».

После правок — **«Сохранить профиль»**.

## 3. Запуск парсинга с квалификацией

В форме парсинга (Rusprofile или Яндекс.Карты):

1. Заполните фильтры как обычно.
2. (Только AI) Выберите профиль из списка **«ИИ-квалификация»**.
3. Чекбокс **«Кросс-обогащение источников»** (рекомендуется): доберёт данные
   из второго источника. Замедлит парсинг, но повысит точность скоринга.
4. Запустите.

После завершения парсинга автоматически стартует квалификация. По её
завершении в чат с ботом придёт сводка: «🔥 12 горячих, ❄ 23 холодных, …».

---

## 4. Что в Google Sheets

После квалификации в таблице появятся новые колонки:

| Колонка | Что значит |
|---------|------------|
| **ИИ-балл** | Универсальный скор 0–100 по «живости» компании |
| **ИИ-статус** | `hot` / `cold` / `skip` / `unknown` / `quota_exceeded` |
| **ИИ-комментарий** | Объяснение от ИИ (≤ 150 символов) |
| **ИИ-сигналы** | Конкретные факты с сайта, на которых основано решение |
| **Зацепка для звонка** | Готовая зацепка для менеджера (только для hot) |
| **✓ позитивные ключи** | Какие слова из профиля нашлись на сайте |
| **✗ негативные ключи** | Стоп-слова, найденные на сайте |
| **Я.Карты рейтинг / отзывы / посл. отзыв** | Сигналы свежести бизнеса |
| **Кросс-источник** | Откуда подтянуты доп. данные: yandex / rusprofile / both |
| **Дата квалификации** | Когда выполнялась |

**Сортировка:** строки идут в порядке `hot first → ai_score desc`. Подсветка:
- 🟢 зелёный — `hot`
- ⚪ светло-серый — `cold`
- 🔘 серый — `skip` (компания мёртвая или нет контактов)
- 🟡 жёлтый — `quota_exceeded` (квота ИИ исчерпана)

## 5. Перезапуск квалификации на старом запуске

В разделе **«История»** у каждой карточки запуска есть кнопка
**«Запустить ИИ»** (или **«Перезапустить ИИ»**, если уже выполнялась).
Спрашивает профиль (если их несколько) и стартует в фоне. По завершении —
сообщение в чат.

Идемпотентность: если квалификация была меньше суток назад с тем же
профилем — компания пропускается. Принудительный запуск — всегда через
эту кнопку (она передаёт `force=true`).

---

## 6. Логи и трассировка

Каждое решение пишется в `logs/qualify/qualify_{run_id}_{date}.jsonl` —
если возникнут вопросы «почему компания cold, а должна быть hot», админ
сможет показать вам полную трассировку по стадиям.

## 7. Часто задаваемые вопросы

**Я не вижу раздел «ИИ-профили».**
У вас тариф Simple. Свяжитесь с поддержкой для подключения AI.

**Стоит ли включать кросс-обогащение?**
Да, по умолчанию. Без него скоринг компаний только из Rusprofile или
только из Я.Карт получит максимум 65 баллов вместо 100, и сортировка
будет менее точной.

**Что будет, если квота закончится посреди парсинга?**
Уже обработанные компании сохранятся как есть. Остальные получат
`ai_status="quota_exceeded"` (жёлтые в Sheets). Запустить заново можно
через кнопку «Перезапустить ИИ» после сброса квоты (через 30 дней).

**Можно ли отредактировать промпт ИИ?**
Промпты лежат в `config/prompts/extract_profile.txt` и
`config/prompts/qualify_company.txt` на сервере. Админ может их править
без передеплоя — изменения подхватываются после перезапуска бота.
