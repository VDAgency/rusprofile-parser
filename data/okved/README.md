# Справочник ОКВЭД

Справочник видов экономической деятельности (ОКВЭД-2, ОК 029-2014)
с «живыми» описаниями и ключевыми словами для поиска. Используется
Mini App'ом и бэкендом для подбора кодов под пользовательский запрос
вида «торговля канцтоварами», «реклама», «автосалоны» и т. п.

## Файлы

| Файл | Что внутри |
|------|-----------|
| `okved_enriched.json` | Иерархия ОКВЭД-2 (разделы → классы → подклассы → группы → подгруппы → виды) с человекочитаемым описанием и ключевыми словами для поиска. |
| `okved_targets.json` | Курируемые наборы ОКВЭД и фильтров под целевые сегменты сувенирной продукции (базовый набор + крупные корпоративные клиенты). |

## Схема `okved_enriched.json`

```json
{
  "version": "2026-05-06",
  "source": "ОК 029-2014 (КДЕС Ред. 2). Описания и ключевые слова составлены вручную.",
  "items": [
    {
      "code": "46.49.3",
      "name": "Торговля оптовая писчебумажными и канцелярскими товарами",
      "level": 5,
      "parent": "46.49",
      "section": "G",
      "section_name": "Торговля оптовая и розничная; ремонт автотранспортных средств и мотоциклов",
      "is_leaf": true,
      "description": "Оптовые поставщики канцелярии, бумаги, ручек, тетрадей, ежедневников.",
      "keywords": ["опт канцтоваров", "канцелярия оптом", "ежедневники"]
    }
  ]
}
```

* `level` — глубина в иерархии: 1 (раздел A–U), 2 (класс XX), 3 (подкласс XX.X),
  4 (группа XX.XX), 5 (подгруппа XX.XX.X), 6 (вид XX.XX.XX).
* `parent` — код родителя (`null` для разделов).
* `is_leaf` — нет дочерних кодов.
* `description` — короткое (1–2 предложения) пояснение «живым» языком: чем
  занимаются такие компании, что продают / производят / делают.
* `keywords` — синонимы и обиходные названия для поиска (нижний регистр).

## Схема `okved_targets.json`

```json
{
  "version": "2026-05-06",
  "comment": "...",
  "presets": [
    {
      "id": "souvenirs_default",
      "title": "Сувенирка: базовый набор",
      "description": "...",
      "codes": ["73.11", "73.12.1", "..."],
      "recommended_filters": {
        "has_phones": true,
        "msp": ["SMALL", "MEDIUM"]
      },
      "notes": "..."
    }
  ]
}
```

`recommended_filters` поддерживает любые поля `SearchFilters` бэкенда
(`has_phones`, `has_emails`, `has_sites`, `msp`, `finance_revenue_from`,
`finance_revenue_to`, и т. д. — см. `src/rusprofile/filters.py`).

## Как обновить справочник

1. **Добавить новый код.** Дописать запись в массив `items` файла
   `okved_enriched.json`. Обязательные поля: `code`, `name`, `level`,
   `parent`, `section`, `section_name`, `is_leaf`, `description`,
   `keywords`. Если меняется иерархия — проверить, что у каждого
   `parent` есть запись в файле.
2. **Поправить описание/keywords.** Просто отредактировать поле в
   нужной записи. Поиск автоматически подхватит изменения после
   рестарта бота / перезагрузки Mini App.
3. **Добавить новый пресет.** Дописать объект в массив `presets`
   файла `okved_targets.json`. Все коды из `codes` должны
   присутствовать в `okved_enriched.json` (юнит-тест это проверит).

## Как обновить классификатор при изменении ОК 029-2014

Росстандарт периодически правит ОКВЭД-2 (мелкие изменения раз в
несколько лет). Алгоритм:

1. Скачать актуальную редакцию (XML/CSV) с classifikators.ru/okved
   или с сайта Минэкономразвития.
2. Сравнить с текущим `okved_enriched.json` по полю `code`:
   * новые коды — добавить с описанием и keywords;
   * удалённые коды — удалить (или пометить устаревшими, если они
     ещё могут встречаться у компаний в Rusprofile);
   * переименованные — обновить `name`.
3. Прогнать тесты `pytest tests/test_okved.py`.

## Тесты

См. `tests/test_okved.py`. Проверяется:

* у каждого кода с непустым `parent` — родитель есть в файле;
* поиск «канцтовары» возвращает `46.49.3` в топе;
* все коды из `okved_targets.json` присутствуют в `okved_enriched.json`.
